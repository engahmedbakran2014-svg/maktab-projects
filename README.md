# إدارة مشاريع المكتب

برنامج عربي (RTL) من صفحة واحدة لإدارة مشاريع المكتب الهندسي: ترتيب المشاريع بالتاريخ واليوم،
توزيع المهام على الفريق، متابعة الموافقات المبدئية وملاحظات الجهات، متطلبات العملاء والكروكي،
الأوامر الخارجية، وحفظ ملف لكل مشروع على جهاز المسؤول.

المكتب: **مكتب عبدالرزاق حكيم للاستشارات الهندسية** — المدينة المنورة.

---

## الملفات

| الملف | الوصف |
|---|---|
| `index.html` | البرنامج كاملاً — صفحة واحدة مستقلة بلا أي مكتبات خارجية |
| `firebase-config.js` | إعدادات قاعدة البيانات المشتركة (اختيارية) |
| `.nojekyll` | يمنع GitHub Pages من معالجة الملفات |

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub باسم مثل `maktab-projects`.
2. ارفع محتويات هذا المجلد إلى المستودع (`Add file` ← `Upload files` ثم اسحب الملفات).
3. من `Settings` ← `Pages`: اختر `Deploy from a branch`، والفرع `main` والمجلد `/ (root)`، ثم `Save`.
4. بعد دقيقة يصبح الرابط: `https://<اسم-حسابك>.github.io/maktab-projects/`

> اجعل المستودع **Private** إن كنت لا تريد أن يطّلع أحد على الكود.
> ملاحظة: مستودع Private مع GitHub Pages يحتاج اشتراك GitHub Pro/Team.

## المشاركة بين الموظفين

البرنامج يعمل على ثلاثة أوضاع، ويختار المناسب تلقائياً:

| الوضع | متى | المشاركة |
|---|---|---|
| **قاعدة بيانات claude.ai** | عند فتحه من رابط الأرتفاكت | مشتركة لحظياً — لا تحتاج أي إعداد |
| **Firebase** | عند تعبئة `firebase-config.js` | مشتركة لحظياً على GitHub Pages |
| **محلي** | بلا إعداد | البيانات على جهاز كل شخص فقط |

### تشغيل المشاركة على GitHub Pages (Firebase)

1. أنشئ مشروعاً مجانياً على <https://console.firebase.google.com>.
2. `Project settings` ← `Your apps` ← أضف **Web App**، وانسخ قيم `firebaseConfig`.
3. الصق القيم في `firebase-config.js`.
4. فعّل **Firestore Database** (ابدأ بوضع Test أو اضبط القواعد).
5. فعّل **Storage** إن أردت رفع الكروكي وصور الملاحظات.
6. ارفع الملف المعدَّل إلى المستودع.

#### قواعد Firestore مقترحة (تعديلها حسب حاجتك)

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;   // مناسب للاستخدام الداخلي فقط
    }
  }
}
```

> القاعدة أعلاه تفتح القراءة والكتابة لمن يعرف الرابط. للاستخدام الجاد
> فعّل **Firebase Authentication** واربط القواعد بالمستخدمين المسجّلين.

## التثبيت على الجوال والمشاركة

- البرنامج يعمل كتطبيق على الجوال (PWA): من قائمة المتصفح «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- زر **📤 مشاركة** (للمدير والمهندس المسؤول) يُخرج **رابط دعوة** ورمز QR يربط جهاز الزميل بقاعدة بيانات المكتب،
  ثم يدخل الزميل برقمه السري الخاص.
- رمز الربط يُحمل بعد علامة `#` في رابط الدعوة، فلا يُرسل لأي خادم ولا يُحفظ في هذا المستودع.
- إذا فُتح البرنامج على جهاز غير مربوط يطلب لصق رابط الدعوة مرة واحدة.

## الدخول والقفل

- عند فتح البرنامج تظهر صفحة الشركة الرسمية مع الشعار، ولا تظهر أسماء الموظفين.
- كل شخص يدخل **برقمه السري الخاص** فيفتح البرنامج على صفحته ومهامه حسب صلاحيته.
- الرقم السري لكل موظف يحدده المسؤول الرئيسي من «الفريق» — ولا يُقبل رمز مكرر.
- يُقفل البرنامج تلقائياً بعد **10 دقائق** من عدم النشاط، ويمكن قفله يدوياً من زر «قفل».
- الأرقام السرية للموظفين محفوظة في قاعدة البيانات وليست في هذا الملف.

## الصلاحيات

| الصلاحية | ما يستطيعه |
|---|---|
| **مسؤول رئيسي** | كل شيء + تعيين المسؤولين + إدارة الفريق + السجل الداخلي |
| **مهندس مسؤول** | مشاريعه وفريقه وتوزيع المهام واعتمادها |
| **موظف** | مشاريعه ومهامه فقط، وتسليم المهمة للمراجعة |

### الأرقام السرية

| الرقم | الوظيفة |
|---|---|
| `ROOT_CODE` | فتح حساب المدير المسؤول · تحويل القائمة · إضافة وتعديل وحذف الفريق |
| `ADMIN_CODE` | سجل التعديلات الداخلي |

القيمتان في هذه النسخة العامة **placeholders** (`0000` و `000000`).
غيّرهما إلى رقميك الحقيقيين: ابحث في `index.html` عن `ADMIN_CODE` و `ROOT_CODE`.

> لا تضع أرقامك السرية الحقيقية في مستودع **Public**.

> الأرقام حاجز تنظيمي داخل الصفحة وليست تشفيراً — من يفتح الرابط ويملك خبرة تقنية
> يستطيع تجاوزها. اقصر الرابط على فريق المكتب.

## المخرجات

- **ملف لكل مشروع على الجهاز**: مجلد باسم المشروع ورقمه يحوي بيانات المشروع (Word)،
  جدول الأعمال ومتطلبات بلدي (Excel)، ملف «ملاحظات + التاريخ» لكل تطوّر، ومجلد الصور.
- **تصدير كامل المشاريع والأعمال** إلى Excel حسب موظف أو كل الموظفين مع أسباب التوقف.
- **طباعة / PDF** لكشف الأعمال القائمة، وصفحة متطلبات العميل، ونموذج العميل.

مولّدات Word و Excel و ZIP مكتوبة داخل الملف نفسه بلا أي مكتبة خارجية.
